# Entrenamiento futuro del módulo «Intenciones»

**Aún no hay videos de entrenamiento incorporados.** Los tres videos KTH del catálogo vecino son muestras para **evaluación**, no entrenamiento.

Para aceptar un futuro clip:
1. Confirmar derechos de uso para entrenamiento y almacenamiento; si se planea publicarlo en GitHub, confirmar expresamente la redistribución pública. Evitar rostros/datos personales innecesarios y usar consentimiento pertinente.
2. Registrar fuente y SHA-256; conservar el archivo original fuera de Git.
3. Convertir solo si hace falta, manteniendo resolución y FPS; evitar cambios de nombre que pierdan trazabilidad.
4. Etiquetar acciones observables, objetos realmente visibles e intervalos de tiempo. Separar personas/escenas por conjuntos para impedir contaminación de evaluación.
5. Mantener videos en almacenamiento local o privado con controles de acceso; **no añadirlos automáticamente al Git público**, aunque exista configuración LFS. Para material propio autorizado, acordar una política de publicación segura.

Clases planificadas (pendientes, NO entrenadas): acción de empujar, movimiento de golpeo, caída observable, arma de fuego visible, arma blanca visible. Proximidad o brazos alzados por sí solos no confirman una agresión.
